# 轻记账 App (qingjiapp)

一款本地优先、支持 AI 语音记账和搭子对话的个人记账工具。纯前端实现，数据保存在浏览器本地存储中，开箱即用。

## 功能亮点

- 📒 **多账本管理**：支持创建多个独立账本，用于不同场景（个人、家庭、旅行等）
- 💰 **三种记账模式**：标准记账、快速记账、预算记账
- 📊 **可视化分析**：月度收支图表、分类占比统计、历史趋势
- 💾 **数据备份**：支持导出/导入 JSON 备份文件
- 🎨 **5 种主题**：毛玻璃、微立体、极简白、深色、小青账
- 🎯 **储蓄目标**：支持设置储蓄目标，按进度打卡记录

## AI 增强功能

- 🎙️ **一句话批量记账**：语音或文字输入一句「今天午餐32，打车18，工资5000」，自动识别金额、分类、收入/支出类型，一次生成多笔账单
- 🤖 **记账搭子元元**：聊天式记账。和虚拟角色对话，支持闲聊、查询、记账。三种性格可选
- ⚙️ **云端 AI 开关**：默认完全离线解析，可选启用云端增强

## 技术栈

- 纯 HTML / CSS / JavaScript，无构建步骤
- Chart.js 用于数据可视化（通过 CDN 加载）
- localStorage 持久化存储
- Web Speech API 用于语音输入（浏览器支持）

## 使用方法

### 方式一：直接打开
直接双击 `accounting-app.html` 文件，在浏览器中打开即可使用。

### 方式二：本地服务器（推荐）
```bash
# Python 3
python3 -m http.server 8080

# Node.js
npx serve .
```
然后在浏览器访问 `http://localhost:8080/accounting-app.html`

## 数据隐私

- 所有账单数据仅存储在您当前设备的浏览器 localStorage 中
- 不发送到任何服务器（除非您手动启用云端 AI）
- 默认完全离线运行
