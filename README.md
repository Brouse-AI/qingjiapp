## 📖 项目简介

轻记账（qingjiapp）是一款注重隐私、本地优先的个人财务管理应用。它结合了现代化的 UI 设计、AI 智能辅助和丰富的数据分析功能，让记账变得简单、有趣且高效。

所有数据默认存储在本地浏览器中，支持加密保护，确保您的财务隐私安全。

---

## ✨ 核心功能

### 🎨 多主题切换
提供 5 种精美的界面主题，满足不同用户的审美需求：

| 主题名称 | 特点 | 适用场景 |
|---------|------|---------|
| **毛玻璃** | 现代感十足的半透明效果，柔和渐变背景 | 喜欢现代设计的用户 |
| **拟物** | 细腻的拟物化设计，丰富的阴影和纹理 | 追求质感的用户 |
| **简约** | 清爽简洁的界面，去除多余装饰 | 喜欢极简风格的用户 |
| **深色** | 护眼的深色主题，适合夜间使用 | 夜间使用 / OLED 屏幕 |
| **轻清** | 清新淡雅的配色，轻松愉快的视觉体验 | 日常使用 |

### 💰 多账本支持
- 创建多个独立账本（如：日常生活、工作报销、副业项目等）
- 各账本数据独立，互不干扰
- 快速切换账本，一键查看不同场景的财务状况

### 🤖 AI 搭子对话（貅宝 Finley）
- **智能记账助手**：用自然语言描述消费，AI 自动识别并记账
- **财务顾问**：貅宝会根据您的消费习惯提供个性化建议
- **情感陪伴**：可爱的貅宝角色设定，让记账不再枯燥
- **对话式查询**：用自然语言询问财务数据
- **IP 形象**：完整的貅宝角色设定，丰富的表情和动画

### 📊 预算管理
- 为每个支出分类设置月度预算
- 实时跟踪预算使用情况
- 超支提醒和预警
- 可视化进度条展示

### 📈 数据分析图表
- **分类饼图**：直观展示各类支出占比
- **趋势折线图**：观察消费走势
- **分类柱状图**：对比不同分类的消费
- **预算进度图**：实时了解预算使用情况
- **月度汇总**：收支平衡一目了然

### 🎤 语音记账
- 支持语音输入记账
- 自然语言理解：「午餐 25 元」「打车 30 元」即可快速记账
- AI 自动识别金额、分类和备注
- 解放双手，记账更便捷

### 🔒 本地加密存储
- **100% 本地存储**：所有数据默认保存在浏览器本地
- **AES 加密**：支持密码加密保护您的财务数据
- **隐私优先**：不上传任何个人财务数据到云端（除非您主动开启云同步）
- **数据导出/导入**：支持 JSON 格式的完整备份和恢复
- **回收站**：误删的记录可以轻松恢复

## 🚀 快速开始

### 方法一：直接打开（最简单）

直接在浏览器中打开 `index.html` 即可使用。

### 方法二：本地开发服务器

```bash
# 进入项目目录
cd qingjiapp

# 启动本地服务器
node server.js

# 在浏览器中访问
# http://localhost:8080
```

### 方法三：GitHub Pages

访问项目的 GitHub Pages 地址即可在线使用。

## 💡 使用技巧

1. **快速记账**：在主页面点击「记账」按钮，输入金额和分类
2. **语音记账**：点击麦克风图标，用语音描述您的消费
3. **查看报表**：切换到「分析」标签，查看可视化报表
4. **设置预算**：在设置中为各分类设置月度预算
5. **切换主题**：点击顶部主题切换按钮，选择喜欢的风格
6. **数据备份**：定期导出 JSON 备份文件，以防数据丢失

## 🎯 技术特点

- **纯前端实现**：无需后端服务器，开箱即用
- **响应式设计**：完美适配手机、平板和桌面设备
- **零依赖运行**：核心功能不依赖外部服务
- **离线可用**：支持 PWA，可以离线使用
- **数据加密**：AES 加密保护敏感数据
- **Chart.js 图表**：丰富的数据可视化
- **现代 CSS**：CSS 变量、Flexbox、Grid 布局
